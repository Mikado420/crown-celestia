# クラウン・セレスティア（試作版）

名作ボードゲームをモチーフにしたミニゲームを、剣と魔法の世界で遊ぶボドゲ大戦の試作です。タイトル画面で遊ぶゲームを選べます。

| ゲーム | 原案 | 人数・時間 |
| --- | --- | --- |
| 酒場のツケ | 6ニムト | 2〜6人・10〜15分 |
| 毒杯の晩餐会 | 藪の中 | 2〜6人・15〜20分 |
| 魔法陣の決闘 | バトルライン | 2〜6人・15分前後 |

## 魔法陣の決闘の遊び方

1. 隣り合う2人の間ごとに魔法陣が並ぶ（2人は7つ、3人は決闘ごとに3つ、4〜6人は2つ）。自分は左右の隣と同時に戦う。
2. 全員が同時に、精霊を1体自分側の魔法陣に置くか、秘術を1枚使う。そのあと精霊か秘術の山から1枚引く。パスはできない。
3. 片側3体の「合計＋役ボーナス」で勝負。ボーナスは「同じ属性の連番＋3」「同じ数字・同じ属性＋2」「連番＋1」。高い方が魔法陣を取り、同点なら先にそろえた方。
4. 相手がもう逆転できなくなった魔法陣は自動で決着する。
5. 魔法陣1つで1点、1つの決闘の陣を全部取ると+1点（2人は4つか隣り合う3つで即勝利+2点）。3ラウンドの合計で競う。4人以上はラウンドごとに席替え。
6. 秘術は9種類（虹の精霊・上位精霊・小精霊・霧の結界・陣の拡張・遠見の水晶・転移・送還・魅了）。手札に2枚まで。

## 毒杯の晩餐会の遊び方

1. 伏せた容疑者3人のうち、一番怪しい（数字が大きい）者が犯人。ただし道化師が紛れていたら逆転し、一番怪しくない者が犯人。道化師自身は犯人にならない。
2. 手番では「調べる（1人をこっそり見る）」か「すり替える（手持ちの人物と入れ替える。抜いた人物は誰も見ずに退場）」を選ぶ。すり替えは1事件に1人1回。
3. 行動のあと、1人について「クロ」か「シロ」を証言する。嘘でもよい。直前に証言された人物は、次の人は調べられない。
4. 2周したら全員が同時に告発する。当たりは「賭け×（外れた人数＋1）」点、外れは−賭け点。本当の証言1つにつき+1点。
5. 事件は人数と同じ数（2人なら6件）。合計点が一番高い人の勝ち。

## 酒場のツケの遊び方

1. 全員が同時に、手札から冒険者を1人選びます。全員がそろうまで選び直せます。
2. 格（数字）の小さい冒険者から順に、4つの卓のどれかに座ります。座る卓は、自分より格が低い中で一番近い冒険者が端にいる卓です。
3. 卓に座れるのは5人まで。6人目は、その卓5人分の勘定をツケで払い、新しい卓の主になります。
4. どの卓の端よりも格が低い冒険者は相席を断られ、好きな卓を1つ選んで勘定を肩代わりします。
5. 10手番で1晩。2人なら4晩、3〜6人なら3晩で終わり、ツケが一番少ない人の勝ちです。

### 人数に合わせた調整

- 使う冒険者は「人数×10＋5」人（4人なら格1〜45）。全員の手札と卓の4人に加え、1人は酔いつぶれて寝ていて、その晩は出てきません。
- 毎晩2人の「大酒飲み」がランダムに現れ、ツケが5になります。
- ツケの基本額：55は7、11の倍数は5、10の倍数は3、5の倍数は2、それ以外は1。

## 友達と遊ぶ

- ホストが「友達を招く部屋を作る」を押すと、5文字の部屋コードと招待リンクが出ます。
- 友達はリンクを開くか、コードを入力して入ります。席が足りなければCPUを呼べます。
- 通信はブラウザ同士の直接接続（WebRTC、[PeerJS](https://peerjs.com/)）です。接続の仲介だけPeerJSの公開サーバーを使います。
- 左上のメニューから、いつでも退出できます。途中で抜けた人の席はCPUが代打ちします。
- ホストが退出するかブラウザを閉じると、部屋が閉じます。
- 会社や学校など一部のネットワークでは、直接接続がつながらないことがあります。

## 公開する（GitHub Pages）

リポジトリの Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にします。
数分後に `https://<ユーザー名>.github.io/crown-celestia/` で遊べます。

## 開発

ビルドは不要です。ES Modules を使うので、ローカルでは簡易サーバー経由で開きます。

```sh
npm run serve   # http://localhost:8000 （python3 が必要）
npm test        # ルールとホスト進行のテスト（Node.js 20 以降）
```

URLに `?fast` を付けると、待ち時間を短くした確認用モードになります。

| ファイル | 役割 |
| --- | --- |
| `js/main.js` | タイトル・ロビー・メニューなど、ゲームをまたぐ画面 |
| `js/host.js` | ホストでの進行（参加者、制限時間、CPU、各プレイヤーに見える情報の配信）。ゲームの種類に依存しない |
| `js/net.js` | PeerJS による部屋の作成と参加 |
| `js/ui.js` `js/sfx.js` | 共通の画面部品と効果音 |
| `js/games/index.js` | ゲームの一覧 |
| `js/games/<ゲーム>/game.js` | ルールの処理（通信や画面に依存しない） |
| `js/games/<ゲーム>/cpu.js` | CPUの思考 |
| `js/games/<ゲーム>/mode.js` | そのゲームの進行（制限時間・CPUの手番・演出待ち） |
| `js/games/<ゲーム>/screen.js` | そのゲームの対局画面と演出 |

新しいゲームを足すときは `js/games/` にフォルダを作り、`index.js` と `main.js` の `SCREENS` に登録します。
