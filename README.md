# クラウン・セレスティア：酒場のツケ（試作版）

天空の王国セレスティアの酒場「酔いどれ竜亭」を舞台にした、2〜6人用の同時出しカードゲームです。
ボドゲ大戦「クラウン・セレスティア」のミニゲーム第1弾の試作です（原案：6ニムト）。

## 遊び方

1. 全員が同時に、手札から冒険者を1人選びます。全員がそろうまで選び直せます。
2. 格（数字）の小さい冒険者から順に、4つの卓のどれかに座ります。座る卓は、自分より格が低い中で一番近い冒険者が端にいる卓です。
3. 卓に座れるのは5人まで。6人目は、その卓5人分の勘定をツケで払い、新しい卓の主になります。
4. どの卓の端よりも格が低い冒険者は相席を断られ、好きな卓を1つ選んで勘定を肩代わりします。
5. 10手番で1晩。2人なら4晩、3〜6人なら3晩で終わり、ツケが一番少ない人の勝ちです。

### 人数に合わせた調整

- 使う冒険者は「人数×10＋5」人（4人なら格1〜45）。全員の手札と卓の4人に加え、1人は酔いつぶれて寝ていて、その晩は出てきません。
- 毎晩2人の「大酒飲み」がランダムに現れ、ツケが5になります。
- ツケの基本額：55は7、11の倍数は5、10の倍数は3、5の倍数は2、それ以外は1。

## 友達と遊ぶ

- ホストが「友達を招く部屋を作る」を押すと、5文字の部屋コードと招待リンクが出ます。
- 友達はリンクを開くか、コードを入力して入ります。席が足りなければCPUを呼べます。
- 通信はブラウザ同士の直接接続（WebRTC、[PeerJS](https://peerjs.com/)）です。接続の仲介だけPeerJSの公開サーバーを使います。
- 左上のメニューから、いつでも退出できます。途中で抜けた人の席はCPUが代打ちします。
- ホストが退出するかブラウザを閉じると、部屋が閉じます。
- 会社や学校など一部のネットワークでは、直接接続がつながらないことがあります。

## 公開する（GitHub Pages）

リポジトリの Settings → Pages で、Source を「Deploy from a branch」、ブランチを `main`、フォルダを `/ (root)` にします。
数分後に `https://<ユーザー名>.github.io/crown-celestia/` で遊べます。

## 開発

ビルドは不要です。ES Modules を使うので、ローカルでは簡易サーバー経由で開きます。

```sh
npm run serve   # http://localhost:8000 （python3 が必要）
npm test        # ルールとホスト進行のテスト（Node.js 20 以降）
```

URLに `?fast` を付けると、待ち時間を短くした確認用モードになります。

| ファイル | 役割 |
| --- | --- |
| `js/game.js` | ルールの処理（通信や画面に依存しない） |
| `js/cpu.js` | CPUの思考 |
| `js/host.js` | ホストでの進行（制限時間、CPU、各プレイヤーに見える情報の配信） |
| `js/net.js` | PeerJS による部屋の作成と参加 |
| `js/main.js` | 画面と演出 |
| `js/art.js` | カード・紋章・正の字などの見た目の部品 |
| `js/sfx.js` | 効果音（Web Audioで合成） |
